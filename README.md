# Хоккейное табло / Hockey Scoreboard

Настольное приложение для управления спортивным табло во время матчей и трансляций. Программа объединяет пульт оператора, вывод счёта на экран, работу с командами, таймером, медиа и удалённым управлением через браузер.

**Версия:** 1.6.18072026  
**Платформа:** Windows

---

## Скачать и запуск

| Файл / папка | Описание |
|--------------|----------|
| [HockeyScoreboard.exe](HockeyScoreboard.exe) | Программа |
| [manual.chm](manual.chm) | Справка |
| [resource/](resource/) | Ресурсы (шрифты, языки, стили, изображения) |

1. Скачайте репозиторий целиком (**Code → Download ZIP**) или клонируйте его.
2. Убедитесь, что рядом с `HockeyScoreboard.exe` лежат `manual.chm` и папка `resource`.
3. Запустите `HockeyScoreboard.exe`.

> Аудио, видео и файл конфигурации в публичную сборку не входят — их нужно добавить отдельно при необходимости.

Исходный код находится в отдельном закрытом репозитории.

---

## Назначение

Приложение предназначено для спортивных арен, студий и операторов, которым нужно:

- вести счёт и время матча в реальном времени;
- выводить табло на отдельный экран или проектор;
- управлять периодами, таймаутами, удалениями и овертаймом;
- показывать логотипы команд, гимн, видеоролики и заставки;
- удалённо управлять несколькими площадками через веб-интерфейс.

## Основные возможности

### Пульт оператора
- Управление счётом, периодами и игровым временем
- Настройка перерывов, овертайма, буллитов
- Учёт удалений (хоккей) и упрощённый режим штрафов
- Корректировка данных матча, редактирование составов

### Табло на экране
- Отдельные окна табло под каждый вид спорта
- Настраиваемый внешний вид: названия, таймер, статистика
- Режимы отображения, заставка, турнирная строка
- Церемония награждения и подиум

### Команды и турнир
- База команд с логотипами и лигами
- Турнирная таблица

### Медиа
- Воспроизведение аудио и видео (гимн, гол, заставки)
- Плейлисты и привязка роликов к событиям
- Поддержка камеры

### Веб-управление
- Встроенный HTTP-сервер для удалённого пульта
- Управление до трёх площадок (A / B / C) из браузера

### Прочее
- Светлая и тёмная тема оформления
- Журнал событий
- Защита от повторного запуска (один экземпляр программы)
