11.1. Назначение и возможности

Web Remote — встроенный веб-сервер программы. Он позволяет показывать счёт в браузере, управлять матчем с телефона или планшета в локальной сети и отдавать данные для титров (например, в vMix).
Сервер работает на том же компьютере, что и пульт оператора. Окно табло на мониторе арены при этом не заменяется: веб-страницы дополняют десктоп, а не подменяют его.

Параметры — секция [WEB_REMOTE] во вкладке Настройки → WEB (10.6). HTML-шаблоны лежат в resource/templates/. Запуск и остановка — вручную (11.2).
Основные возможности
Публичное табло
Корневой адрес http://IP:порт/ отдаёт HTML-шаблон из WEB_REMOTE.publicfile (по умолчанию public_vertical.html). Страница показывает счёт, время, названия и логотипы команд и обновляется через API / WebSocket.
  • Включение: public = 1.
  • Другие шаблоны в resource/templates/: горизонтальный, заглушка и др. — см. 11.4.
Панель управления (admin)
Адрес http://IP:порт/control (путь задаётся url_control). Шаблон — admin.html. С панели можно менять счёт, период, запускать и останавливать таймер.
  • Включение: control = 1.
  • Доступ защищён авторизацией (11.6).
  • Число площадок A/B/C — num_fields (1–3).
Синхронизация с десктопом
Программа на ПК — основной источник данных матча. Изменения с веб-панели передаются обратно на операторский пульт и на открытое табло арены. Изменения с десктопа уходят на сервер и сразу видны в браузерах.

Удобная схема: главный оператор за ПК ведёт матч и табло; помощник с планшета дублирует счёт или помогает в перерыве. Оба видят одно и то же состояние.
Логотипы
Файлы команд и лиг отдаются по URL:
  • /logos/ — из resource/img/teams/;
  • /logos/leagues/ — логотипы лиг.
Публичная страница и admin подставляют их автоматически после запуска сервера.
Интеграция с vMix
При vmix = 1 доступен GET /api/vmix — JSON со счётом, временем и названиями команд (в том числе для нескольких площадок). Подробнее — 11.8.

Порт по умолчанию — 8080 (WEB_REMOTE.port). Выбор IP и сеть — 11.3.

Web Remote рассчитан на локальную сеть арены (Wi-Fi / LAN). Не выставляйте панель управления в интернет без дополнительной защиты. Для доступа с телефона устройство должно быть в той же подсети, что и ПК оператора.
Что Web Remote не заменяет
  • Окно табло на втором мониторе / проекторе — по-прежнему открывается из программы (6.1).
  • Сирену, гимны, видео гола и диктора — это медиа на ПК (раздел 9).
  • Полный набор настроек матча — только в десктопном окне настроек.
    
    Дальше по разделу: сначала запустите сервер (11.2), выберите IP (11.3), затем откройте публичную страницу или панель управления.
