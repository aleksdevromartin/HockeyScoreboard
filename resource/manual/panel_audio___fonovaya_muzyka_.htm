9.1. Панель аудио — фоновая музыка

Панель инструментов «Аудио» управляет фоновой музыкой из выбранного каталога. Список треков также доступен на вкладке «Аудио» в центральной области и в блоке превью справа.
Как показать панель
1. ПКМ по главному окну → Панель инструментов → отметьте «Аудио».
2. Состояние сохраняется в TOOLBAR.panelaudio (1 — видна, 0 — скрыта).
Кнопки панели
Кнопка

Воспроизвести

Случайный
Случайный трек из включённых (зелёная точка); при автопереходе дальше — снова случайный
Стоп
Остановить воспроизведение и автопереход
Следующий
Следующий трек
Автоматическое воспроизведение следующего трека
В Настройки → Аудио и видео есть чекбокс «Автоматическое воспроизведение следующего трека» (AUDIO.audio_auto_next, по умолчанию включён).
Значение
Поведение после окончания трека
1 (вкл.)
Играет следующий: после Воспроизвести — по порядку списка; после Случайный — случайный из отмеченных
0 (выкл.)
Звук останавливается — следующий трек только вручную

Режим запоминается по последней кнопке: если нажали Случайный, автопереход остаётся случайным, пока не нажмёте Воспроизвести или Стоп. Сирена, гол, гимн и речь диктора прерывают фоновый плейлист.
Плейлист audio.json
С версии 1.6 фоновая музыка работает через JSON-плейлист (аналогично видео). Файл содержит имя плейлиста, каталог и список треков:

{
  "name": "Название папки",
  "directory": "D:/Музыка/...",
  "tracks": [
    {
      "name": "Название трека",
      "path": "01. track.mp3",
      "folder": "",
      "duration": "3:45",
      "enabled": true
    }
  ]
}
  • path — обычно относительный путь внутри directory (подпапки сохраняются).
  • enabled — участвует ли трек в режиме «Случайный» (зелёная / серая точка).
  • folder — подпапка для группировки в таблице.
Клик по точке у трека сразу сохраняет статус в audio.json.
Дерево каталогов в таблице
Если в audio_dir есть подпапки, список строится деревом:
  • строки «Каталог …» — папки (курсив); в колонке длительности — суммарное время и число треков;
  • под ними — вложенные треки с отступом;
  • клик по точке у каталога включает или выключает все треки в этой папке (включая вложенные) для режима «Случайный».
Когда список пересчитывается
Ситуация
Поведение
Старт программы, audio_auto_update = 1
Сканирует audio_dir (включая подпапки), подтягивает статусы enabled из JSON, перезаписывает плейлист
Старт, audio_auto_update = 0
Только читает audio.json — новые файлы в папке сами не появятся
Выбор каталога кнопкой (настройки / превью)
Всегда полное сканирование; статусы совпадающих путей сохраняются
Сохранение настроек без смены каталога
Как при старте: по флагу автообновления или только чтение JSON

Чекбоксы «Автообновление плейлиста аудио» и «Автоматическое воспроизведение следующего трека» — во вкладке Настройки → Аудио и видео (10.7). Ключи: AUDIO.audio_auto_update, AUDIO.audio_auto_next.
Параметры
Ключ
Назначение
SYSTEM.audios
Путь к файлу плейлиста (по умолчанию resource/json/audio.json)
AUDIO.audio_dir
Каталог с файлами .mp3 (обход с подпапками)
AUDIO.audio_auto_update
1 — при старте сканировать каталог; 0 — только JSON
AUDIO.audio_auto_next
1 — после окончания трека играть следующий (Play — по списку, Random — случайный); 0 — остановить
AUDIO.audio_play
1 — автозапуск случайной музыки в перерывах матча; 0 — только вручную
AUDIO.volume
Громкость 0.0–1.0 (регулятор в превью)
Как настроить и запустить
1. Откройте Настройки → Аудио и Видео и укажите каталог («Выберите каталог с аудио файлами») — или кнопку выбора каталога в превью-плеере.
2. При необходимости включите «Автоматическое воспроизведение следующего трека» и сохраните настройки.
3. Список обновится: колонки отметки, путь, название, длительность; подпапки группируются.
4. Зелёной/серой точкой отметьте треки для режима «Случайный» (статус пишется в JSON).
5. Выделите строку → Воспроизвести (по списку) или нажмите Случайный.
6. При audio_play = 1 во время игры музыка затухает, в перерыве/на паузе может стартовать снова автоматически.
 

Воспроизведение идёт через pygame. При голе, видео на табло или некоторых удалениях фоновая музыка может остановиться или затухнуть.

Если список пуст — проверьте, что в каталоге есть .mp3, путь audio_dir доступен, и при выключенном автообновлении файл audio.json не пустой. После добавления новых треков в папку включите автообновление или заново выберите каталог.
