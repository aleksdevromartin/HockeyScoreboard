15.4. Параметры config.ini

Файл resource/config.ini — главный файл настроек программы. Обычно его меняют через окно «Настройки», диалоги вида табло и меню; ручное редактирование допустимо только при закрытой программе.

Не правьте config.ini во время работы приложения — изменения будут перезаписаны. Перед правкой сделайте копию файла. Лицензию ([KEY]) не копируйте на другой ПК как способ активации.

Логические флаги чаще всего: 1 = да, 0 = нет. Цвета — HEX без символа # (например ffffff). Пути к файлам — относительно корня программы или абсолютные. Список файлов рядом с конфигом — 12.3; сценарии настроек — раздел 10.
Содержание
1. [KEY] — лицензия
2. [SYSTEM] — общие параметры
3. [TOOLBAR] — панели
4. [VID] — вид табло
5. [TEXT] — тексты, шрифты, цвета
6. [AUDIO] — звук
7. [VIDEO] — видео
8. [IMG] — изображения
9. [TABLE] — турнирная таблица
10. [WEB_REMOTE] — веб-пульт
11. Секции видов спорта
12. [PROTOCOL] — протокол
13. [HOTKEYS] — горячие клавиши

Секция управляется программой и хранилищем лицензии (реестр / файл). Ручная правка обычно не нужна.
