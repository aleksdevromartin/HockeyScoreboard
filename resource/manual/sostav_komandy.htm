4.9. Состав команды

Состав игроков используется при полном вводе гола (SYSTEM.goal_simplified = 0): для выбора авторов и ассистентов в диалоге «Авторы гола». Состав не связан с базой команд teams.json — это отдельные файлы для текущего матча.
Как открыть
1. Убедитесь, что упрощённый гол выключен (диалог «Вид табло» или goal_simplified = 0).
2. Нажмите на название команды (HOME или GUEST) на панели оператора.
3. Откроется диалог «Состав команды».

При включённом упрощённом голе название команды не является ссылкой — состав недоступен с панели оператора.


Каталог фото команды — team.photos (по умолчанию resource/img/players/{название_в_транслите}). У игрока поле photo может быть null. Без фото на табло остаётся логотип команды.

При импорте допускаются альтернативные имена полей: num, surname, name, pos. Роли А/К автоматически приводятся к A/K. Амплуа и роль могут быть пустыми.
Утилита ImportRoster (TXT / DOC / XLS)
Если состав пришёл не в JSON, а списком в текстовом файле, Word или Excel, используйте утилиту ImportRoster.
Что
Подробности
Запуск
Windows: ImportRoster.exe (меню Пуск → «Импорт состава»);
Linux: import-roster или /opt/HockeyScoreboard/ImportRoster (ярлык «Импорт состава»);
из исходников: python script/import_roster_gui.py
Форматы
.txt, .csv, .doc/.docx, .xls/.xlsx
Строка игрока
10 Иванов Сергей — достаточно номера и ФИО. Амплуа и роль необязательны; их можно выбрать в таблице после загрузки
Редактирование
Добавление, удаление, дублирование строк; амплуа G/D/F и роль K/A из списков (или «—»)
Куда сохранить
Библиотека resource/players/, рабочий состав хозяев/гостей (rosters/home.json / guest.json) или любой JSON-файл

После сохранения в библиотеку откройте состав в программе (клик по названию команды) и нажмите «Импорт состава», выбрав созданный JSON. Либо сохраните сразу в home.json / guest.json.
Примеры исходных файлов в исходниках проекта: resource/samples/roster_example.txt, roster_example.xlsx.
Примеры исходных файлов в исходниках проекта: script/samples/roster_example.txt, roster_example.xlsx.
Типичный порядок перед матчем
1. Выберите команды из базы (4.2).
2. Выключите «Упрощённый гол» в «Вид табло».
3. При необходимости подготовьте JSON через ImportRoster из TXT/DOC/XLS.
4. Кликните по названию HOME → импортируйте или введите состав хозяев.
5. Повторите для GUEST.
6. Во время матча при голе выбирайте авторов в диалоге (6.9).

Подготовьте файлы составов заранее в resource/players/ с именами команд — на арене достаточно импортировать их одним нажатием.
