Структура папок программы

Все пути в программе задаются относительно папки с исполняемым файлом (HockeyScoreboard.exe на Windows; на Linux — каталог установки, например /opt/HockeyScoreboard/). При запуске программа работает из этой папки.
Корневая папка
Файл / папка
Назначение
HockeyScoreboard.exe
Главный исполняемый файл программы (Windows)
ImportRoster.exe
Утилита импорта составов (TXT/DOC/XLS/Pages → JSON), см. 4.9
manual.chm
Файл справки (открывается кнопкой «Справка»)
hockey.ico
Иконка приложения
resource/
Настройки, медиа, справочники (см. ниже)
log/
Журналы работы (создаётся автоматически)
Папка resource/
Основной каталог пользовательских данных и настроек.
Файл / папка
Назначение
resource/config.ini
Главный файл настроек — язык, тема, таймер, табло, аудио, видео, WEB и др.
resource/json/
JSON-справочники: команды, удаления, плейлисты, турнирная таблица, заголовки, changelog, судьи протокола
resource/json/teams.json
База лиг и команд (названия, логотипы, города)
resource/json/penalties.json
Справочник видов удалений (хоккей)
resource/rosters/
Составы игроков текущего матча (home.json, guest.json)
resource/players/
Каталог импорта и экспорта файлов составов; сюда же сохраняет утилита ImportRoster.exe (TXT/DOC/XLS/Pages → JSON, см. 4.9)
resource/json/videos.json
Плейлист видеороликов для панели видео
resource/json/audio.json
Плейлист фоновой музыки (треки, статусы, каталог)
resource/json/tournament_table.json
Данные турнирной таблицы
resource/json/arbiters.json
Список судей для диалога протокола (фамилия и имя)
resource/json/changelog.json
Примечания к релизу (Справка → Примечания к релизу)
resource/users.login
Учётные записи для доступа к веб-пульту
resource/json/headers.json
Заголовки и колонтитулы
resource/lang/
Файлы перевода интерфейса (*.elang). Правка: Справка → Редактор словарей (Справка)
resource/templates/
HTML-шаблоны веб-табло и панели управления (admin.html и др.)
resource/style/
Стили оформления (светлая и тёмная тема)
resource/font/
Шрифты табло (Seven Segment, Bahnschrift, Anton и др.)
resource/img/icon/
Иконки кнопок интерфейса (SVG и PNG)
resource/audio/
Звуковые файлы по умолчанию (гудок, гимны, buzzer)
resource/video/
Видеофайлы по умолчанию (гимн, гол)
resource/regulations/
Файлы регламентов соревнований (*.rules)
resource/games/
Снимки матчей (*.game) — импорт/экспорт игры
resource/license.dat
Данные лицензии (Linux; в Windows — реестр)
state.json
Состояние матча для веб-пульта (создаётся при работе WEB-сервера)
Папка resource/img/
Подпапка
Назначение
resource/img/teams/
Логотипы команд (PNG). Путь к файлу хранится в teams.json
resource/img/leagues/
Логотипы лиг и турниров
resource/img/bg/
Фоновые изображения табло и турнирной таблицы
resource/img/players/
Фотографии игроков (подпапки по командам). Путь в составе — team.photos, см. 4.9
resource/img/icon/
Иконки кнопок интерфейса
Папка log/
Журналы создаются автоматически при работе программы. Имя файла: ДД-ММ-ГГГГ-ТИП.log.
Тип
Содержание
-APP.log
Основные действия оператора (гол, период, настройки и т.д.)
-Web.log
События веб-сервера и удалённого управления
-DBUG.log
Отладочная информация (при включённом режиме debug)
Просмотр логов — через встроенный просмотрщик (кнопка «Журнал» на панели инструментов).
Основные секции config.ini
Секция
Что хранит
[KEY]
Лицензия: статус, ключ, UUID компьютера
[SYSTEM]
Язык, тема, вид спорта, таймер, периоды, пути к JSON-файлам, монитор
[TOOLBAR]
Видимость панелей инструментов
[VID]
Режимы отображения табло
[TEXT]
Названия команд, подписи полей, шрифты и цвета табло
[AUDIO], [VIDEO]
Пути к медиафайлам, громкость
[IMG]
Фоны, логотипы, флаги
[TABLE]
Турнирная таблица
[WEB_REMOTE]
Порт, шаблоны, доступ, vMix
[HOCKEY], [FOOTBALL] …
Правила для каждого вида спорта
[PROTOCOL]
Постоянные поля протокола матча (судьи, турнир, шаблон)
[HOTKEYS]
Горячие клавиши пульта (см. 1.7)

Редактируйте config.ini только при закрытой программе или через окно «Настройки». Некорректное редактирование может нарушить работу табло. Перед изменениями сделайте резервную копию файла. Полный список параметров — 15.4.

Для переноса настроек на другой компьютер достаточно скопировать папку resource/ и пользовательские медиафайлы. Лицензия привязана к компьютеру и переносится отдельно.
