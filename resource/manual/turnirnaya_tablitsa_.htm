8.3. Турнирная таблица

Турнирная таблица показывается на табло между матчами или вместо игрового экрана. Данные хранятся в resource/json/tournament_table.json (путь — TABLE.data_file). Число команд в таблице совпадает с числом мест награждения SYSTEM.award_teams (от 3 до 8). Краткий обзор с точки зрения табло — 7.10.

см. Окно редактирования турнирной таблицы, Окно выбора картинки с турнирной таблицей, Окно ввода данных для турнирной таблицы
Как открыть
1. Нажмите «Новый матч» и откройте окно табло (7.1).
2. На панели «Табло» нажмите «Турнирная таблица» (подсказка: «Отобразить турнирную таблицу»).
Какой диалог откроется — зависит от режима TABLE.mode (см. ниже). В режиме данных кнопка неактивна, пока табло закрыто.
Два режима: TABLE и BG
Выбор: Настройки → Окно табло → «Режим турнирной таблицы».

Редактор (режим TABLE)
Заголовок окна: «Редактирование турнирной таблицы».
Команды
  • Для каждой строки: «Выбрать команду» из базы, отображаются название и локация (город).
  • Логотип подставляется из карточки команды.
Матрица результатов
  • Столбцы: команда, соперники (или номера), З : П (голы), Очки, Место.
  • Двойной щелчок по ячейке матча открывает диалог «Результат матча»:
  • счёт в формате 5 : 4;
  • очки за матч: 0, 1 или 2.
  • Ячейка «команда против себя» — прочерк.
Авторасчёт
  • Очки суммируются по всем сыгранным матчам.
  • Места сортируются по очкам (при равенстве — одинаковое место, следующее пропускается).
  • Колонка голов — сумма забитых и пропущенных.

Режим BG (картинка)
Диалог «Турнирная таблица»: выбор фонового изображения, пред просмотр, «Показать на табло» / «Скрыть с табло». Файл сохраняется в IMG.bg_table. Удобно, если таблицу готовят в графическом редакторе.
Связь с награждением
В диалоге церемонии кнопка «Из турнирной таблицы» подставляет команды по полю place в JSON. Если мест нет — сообщение: «В турнирной таблице нет команд с указанными местами». Подробнее — 8.4.

После правок нажмите «Сохранить», затем «Показать на табло» — иначе на экране зрителей останутся старые данные.
