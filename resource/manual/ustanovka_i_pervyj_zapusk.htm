Установка и первый запуск

Установка под Windows
Шаг 1. Распаковка
1. Скопируйте папку с программой на диск компьютера (рекомендуется локальный SSD, не сетевой диск).
2. Не переименовывайте и не удаляйте вложенную папку resource/ — программа обращается к ней по относительным путям.
3. Файл manual.chm должен находиться в корне папки программы (рядом с исполняемым файлом).
Шаг 2. Первый запуск
1. Запустите HockeyScoreboard.exe (или двойной щелчок по ярлыку).
2. При первом запуске программа создаёт или загружает файл настроек resource/config.ini.
3. Рабочая папка программы автоматически устанавливается в каталог, где находится EXE-файл.
4. Рядом с программой может быть утилита ImportRoster.exe — импорт составов из TXT/DOC/XLS/Pages в JSON (см. 4.9).

Программа не допускает одновременный запуск двух копий. Если появится сообщение «Программа уже запущена», закройте предыдущий экземпляр через диспетчер задач или кнопку «Выход» в боковом меню.
Шаг 3. Активация лицензии
При первом запуске (или при отсутствии действующей лицензии) откроется окно Активация лицензии:
1. Запишите ID компьютера (формат XXXX-XXXX-XXXX-XXXX-XXXX) — он понадобится для получения лицензионного ключа у поставщика.
2. Выберите один из вариантов:
  • Пробная версия — 30 дней бесплатного использования (один раз на компьютер);
  • Ввести лицензионный ключ — полная или временная лицензия.
    3. Нажмите Активировать или Пробная версия.
Подробнее о типах лицензий — в разделе Лицензирование.
Шаг 4. Базовая настройка
После активации рекомендуется выполнить минимальную настройку:
1. Нажмите кнопку Настройки (шестерёнка на панели или в боковом меню).
2. На вкладке Игра выберите язык, тему и вид спорта.
3. На вкладке Экран укажите номер монитора для табло (обычно 2, если подключён второй дисплей).
4. На вкладке Команды проверьте или добавьте команды турнира.
5. Нажмите Применить или OK.
Шаг 5. Проверка табло
1. Нажмите кнопку Новый матч на панели инструментов.
2. Выберите команды и откройте окно табло (кнопка предпросмотра / «Показать табло»).
3. Убедитесь, что табло отображается на нужном мониторе и данные обновляются при изменении счёта.
Установка под Linux
Установка под Linux
На Linux программа поставляется в виде пакета .deb или готовой папки с исполняемыми файлами.
Установка из .deb
1. Установите пакет (например: sudo dpkg -i HockeyScoreboard_….deb).
2. Запуск: команда hockey-scoreboard или ярлык в меню приложений.
3. Утилита импорта составов: команда import-roster (ярлык «Импорт состава»).
4. Файлы программы обычно находятся в /opt/HockeyScoreboard/; данные — в каталоге resource/ рядом с программой.
Запуск из папки
1. Скопируйте папку дистрибутива на диск (не удаляйте resource/).
2. Запустите HockeyScoreboard; при необходимости рядом есть ImportRoster.
3. Данные лицензии на Linux хранятся в файле resource/license.dat (в Windows — в реестре).

Для просмотра справки CHM под Linux может потребоваться установить программу xchm. Программа также пытается открыть CHM через эту утилиту автоматически.
Обновление версии
1. Сохраните резервную копию папки resource/ (особенно config.ini, teams.json, пользовательские медиафайлы).
2. Установите новую версию в отдельную папку или замените файлы программы, сохранив настройки.
3. Запустите программу и проверьте работу лицензии и табло.

Не удаляйте ключи лицензии в реестре Windows (HKEY_CURRENT_USER\Software\ADMSportsScoreboard) без необходимости — это может потребовать повторной активации.
